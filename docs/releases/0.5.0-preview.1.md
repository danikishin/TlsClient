# TlsClient 0.5.0-preview.1

The first complete preview of TlsClient: a session-oriented managed C# HTTP client
powered exclusively by SharpTls.

## Highlights

- Managed HTTP/1.1 and HTTP/2 with HPACK/Huffman, multiplexing, flow control, trailers,
  cancellation, and graceful draining.
- Coherent Chrome 133, Firefox 148, and OkHttp/Android 11 TLS + HTTP behavior presets.
- Cookies, redirects, bounded decompression, pooling, DNS refresh, Happy Eyeballs,
  streaming, explicit retries, and HTTP/SOCKS proxy routing.
- ClientHello/fingerprint tooling, ECH discovery, protected TLS session persistence,
  client certificates, pins, and OpenTelemetry diagnostics.
- 108 tests, deterministic fuzzing, performance budgets, protocol review evidence,
  reproducible NuGet/symbol archives, Source Link, SPDX SBOM, and provenance
  attestations.

This is a preview: public APIs may change before `1.0.0`. HTTP/3 is intentionally
deferred, and certificate/hostname validation cannot be disabled through this release.

See the
[changelog](https://github.com/danikishin/TlsClient/blob/main/CHANGELOG.md) for the full
feature and boundary list.
