# TlsClient 0.6.0-preview.1

This preview upgrades the managed TLS engine and adds an explicit, opt-in server
certificate validation escape hatch for controlled testing.

## Highlights

- Pins the exact `SharpTls 0.9.0-preview.5` package.
- Uses SharpTls's corrected revocation handling, allowing unavailable revocation
  evidence to soft-fail only after all other chain and hostname checks succeed.
- Adds `TlsSessionOptions.DangerouslySkipServerCertificateValidation` for local test
  endpoints with deliberately invalid certificates.
- Keeps certificate and hostname validation enabled by default.
- Continues to enforce TLS `CertificateVerify`, handshake authentication, custom
  evidence validation, and configured TlsClient SPKI pins during the dangerous bypass.
- Updates the public API baseline, deterministic lock files, profile manifest, package
  verification, CI metadata, and certificate documentation.

> [!WARNING]
> Enabling `DangerouslySkipServerCertificateValidation` permits active
> man-in-the-middle attacks. It is intended only for controlled testing and must not be
> enabled in production.
