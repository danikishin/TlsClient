# Support

TlsClient is a community-maintained open-source project.

- Use [GitHub Discussions](https://github.com/danikishin/TlsClient/discussions) for
  usage questions, design ideas, and integration help.
- Use [GitHub Issues](https://github.com/danikishin/TlsClient/issues) for reproducible
  bugs and scoped feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Include the TlsClient, SharpTls, .NET, operating system, and architecture versions with
technical reports. Support is best effort; the supported-version policy is documented
in [docs/SUPPORTED-VERSIONS.md](docs/SUPPORTED-VERSIONS.md).
